Everything a compressor should do

Built for photographers, web developers, and anyone who needs a picture to fit in an email.

Live before / after

Drag the divider across the picture, zoom to 1600% to inspect every pixel, or hold Space to flip back to the original.

Auto quality

Finds the smallest file that still looks the same, measured with SSIM. Every result shows its similarity score.

Target file size

Need it under 200 KB? Set the size and each picture gets the highest quality that fits.

Sharp resizing

Fit within a box, set a width, height or percentage, with Lanczos3 or Magic Kernel Sharp resampling in linear light.

Privacy control

Strip all metadata, keep only the colour profile, or keep EXIF without the GPS location. Orientation is always right.

Whole folders

Drop hundreds of pictures or folders. They compress in parallel on every core and save into a folder you pick, without overwriting anything.

Reads everything

JPEG, PNG, WebP, AVIF, iPhone HEIC, TIFF, BMP, GIF and JPEG XL in; JPEG, WebP, AVIF or PNG out.

Expert JPEG controls

Progressive, chroma subsampling, smoothing, nine quantization tables, extra trellis passes and separate colour quality.

How it works

One codebase gives the native apps and the web app. The compression engine is identical everywhere.

WebAssembly codecs

MozJPEG, libwebp, libavif and OxiPNG, the same encoders the best web tools use, running in a pool of background workers, one per CPU core.

React + TypeScript

The interface: batch list, before/after viewer, settings, quality search (binary search on size or SSIM) and lossless EXIF editing.

Rust (Tauri 2)

The native shell: Save dialogs, writing a whole batch into a folder without overwriting, opening pictures from the command line. Small installers, because it uses the web engine already on your system.

GitHub Actions

Builds every installer from this source code, signs the Android app, and publishes checksums with each release.
